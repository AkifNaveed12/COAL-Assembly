# COAL — 8086 Assembly

A practical learning repository for **Computer Organization & Assembly Language (COAL)** using the **8086 architecture and emu8086**.

This repository contains lab programs, practice exercises, and quick revision notes covering the fundamentals of 8086 Assembly.

## 📚 Contents

- 8086 Registers
- Assembly program structure
- Data and memory
- `MOV`, `ADD`, `SUB`, `INC`, `DEC`, `MUL`
- ASCII and character conversion
- DOS `INT 21H` services
- Register manipulation
- Swapping values
- Basic arithmetic
- FLAGS
- emu8086 Single-Step debugging
